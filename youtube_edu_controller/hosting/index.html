영상 보는 시간이
배우는 시간이 되도록

큐타임(QTime)은 아이가 영상을 보는 중간중간 학년에 맞는 퀴즈를 풀며 스스로 학습 습관을 기르도록 돕는 앱입니다. 보호자가 학습 간격과 문제 수를 정하고, 아이는 정답을 맞히면 다시 영상을 이어서 볼 수 있습니다.

⏱ 학습 타이머

보호자가 정한 시간마다 영상이 잠시 멈추고 퀴즈가 나옵니다.

📚 학년별 퀴즈

초등 1학년부터 고등 3학년까지 학년에 맞는 문제를 출제합니다.

👍 아이 취향 추천

아이가 좋아요한 영상과 담은 채널을 바탕으로 영상을 추천합니다. 아이의 기록은 보호자 YouTube 계정과 분리해 앱 안에만 저장합니다.

👪 보호자 관리

보호자 계정으로 학습 설정과 아이가 담은 채널을 관리합니다.

YouTube API 사용 안내

큐타임은 영상 검색·재생과 채널 정보 표시에 YouTube API Services를 사용합니다. 큐타임은 YouTube의 비공식 앱이며 Google LLC와 제휴하거나 후원받지 않았습니다. YouTube 및 관련 상표는 Google LLC의 자산입니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

Google 계정 데이터 사용

보호자가 Google 계정으로 로그인하면 이름·이메일·프로필 사진으로 보호자 계정을 만듭니다. 보호자가 직접 요청한 경우에만 YouTube 구독 목록을 읽어(youtube.readonly), 보호자가 고른 채널을 아이 채널 목록에 추가합니다. 자세한 내용은 개인정보처리방침을 확인해주세요.
